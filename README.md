# Felipe Nunes Menegotto — Portfólio & Currículo

Site de portfólio pessoal e currículo online, desenvolvido como uma **Single Page Application** estática, pronta para hospedagem no **GitHub Pages**.

🔗 **[meneguinha.github.io/CV-felipemenegotto](https://meneguinha.github.io/CV-felipemenegotto/)**

---

## 🚀 Sobre o Projeto

Este site apresenta minha trajetória profissional, projetos de dados e habilidades técnicas de forma visual e interativa, voltado para recrutadores e gestores de contratação nas áreas de **Análise de Dados** e **Desenvolvimento de Software**.

---

## ✨ Funcionalidades

- **Dark / Light Mode** — alternância de tema com persistência via `localStorage`
- **Accordion de Projetos** — cards expansíveis com links para apps e dashboards
- **Smooth Scrolling** — navegação suave entre seções
- **Scroll Reveal** — animações de entrada ao rolar a página
- **Barras de Idiomas** — animadas via Intersection Observer
- **Totalmente Responsivo** — layout mobile-first

---

## 🛠️ Tecnologias

| Camada | Tecnologia |
|--------|-----------|
| Estrutura | HTML5 semântico |
| Estilo | CSS3 puro (variáveis, grid, flexbox, animações) |
| Lógica | JavaScript vanilla (ES6+) |
| Fontes | Google Fonts — Inter + JetBrains Mono |
| Hospedagem | GitHub Pages |

> Sem frameworks, sem dependências, sem build step.
